# Independent audio export

TRAILER-06 qualifies at most four saved AUDIO layer occurrences in one composition. Music, voiceover and SFX are readable operator names on the existing AUDIO model. Reusing an immutable Asset/version creates another layer occurrence, not an imported version. The limit includes muted and disabled occurrences and is an export policy, not a permanent composition schema limit.

New jobs use `studio-editorial-render-spec-v3`. The spec retains the complete saved composition and additionally binds an ordered audio mix: canonical layer order, stable layer ID/name, source Asset/version/content hash/manifest digest, provenance digest, enabled/muted/solo selection, start/duration/source offset in exact 48 kHz samples, gain and local fade sample lengths. Visual solo semantics remain unchanged. V1/V2 specs retain their original byte-addressed readers, preset identity and legacy execution graph; no historical job, receipt or output is rewritten.

The `ORDERED_STEREO_SAMPLE_SUM_V1` mix first uses the existing explicit 48 kHz stereo conversion. Each source is then trimmed to its admitted half-open source interval, timestamps reset locally, saved dB gain applied, and linear fades applied within that local interval. An exact sample delay contributes silence before the saved composition start. The bounded mix uses `amix` with `normalize=0`, `dropout_transition=0`, and `duration=longest`, plus an exact-duration silent stereo master and final sample trim. No automatic gain compensation, normalization, ducking, compressor, limiter, looping or stretching is introduced. Insufficient source coverage fails before mixing. The existing 25 fps visual grid is unchanged; audio events and fades use the 48 kHz sample clock.

Before video encoding/publication, v3 writes an owned temporary unclamped stereo `f32le` mix, bounded to duration × 48,000 × 2 × 4 bytes (115,200,000 bytes at the five-minute maximum). The storage gate includes this staging allocation. A streaming scanner checks exact byte/sample count and every finite sample, rejects absolute sample peaks above 1, and computes peak, RMS and nonzero count. Encoding consumes this validated temporary PCM; canonical editing remains the original independent layers and source references. Owned staging cleanup removes the temporary mix with the rest of the render workspace.

A clipping failure persists `AUDIO_MIX_CLIPPING`, the measured sample peak and an instruction to lower saved track gains. No output is completed, no gain is changed and no automatic retry occurs. Completed v3 outputs include a ledger-authenticated `audioMixValidation` report, also bound into `probeDigest`; v1/v2 output records may omit it. This is sample clipping protection, not true-peak, broadcast loudness or subjective listening certification. The completed rendered output remains the audiovisual review surface; live synchronized multitrack monitoring is not implemented.

The pure focused suite is `scripts/test-animation-studio-audio-mix.mjs`; render/history/publication compatibility is covered by `scripts/test-animation-studio-editorial-v2-render.mjs`. Real qualified-tool audio cases and independent PCM/AAC comparisons belong to the isolated TRAILER-06 acceptance record. The retained TRAILER-05 everyday launcher and runtime are not upgraded by this source change.
