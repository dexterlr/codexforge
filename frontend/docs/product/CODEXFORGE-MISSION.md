CodexForge is a local-first AI developer workspace for planning, understanding, editing safely, reviewing evidence, and coordinating future tool execution behind explicit approvals.

The product is not a generic chatbot and not an autonomous executor. It is a structured engineering runtime with Brain memory, file intelligence, patch review, evidence grounding, task readiness, capability readiness, and creative/artifact planning.

## Safety Commitments

- No silent mutation.
- File mutation is approval-gated and not automatic.
- `apply-diff` requires explicit tool-policy approval.
- Patch review surfaces prepare evidence, approvals, rollback plans, test plans, and simulations only.
- `write-file` and `run-command` remain blocked unless future explicit approval paths exist.
- Broker execution is blocked.
- Creative Studio is preview-only.
- Capability Cockpit does not execute Blender, Unreal, ComfyUI, render jobs, broker jobs, or PC/camera control.
- PC/camera features require explicit future session consent and are not active automation.
- The graph visual layer does not mutate graph state, and the 3D Brain graph has a 2D fallback.
- Local deterministic logic is preferred for core planning.
