# CodexForge Mission

CodexForge is a local-first AI developer workspace for planning, understanding, editing safely, and coordinating future tool execution behind explicit approvals.

The product is not a generic chatbot and not an autonomous executor. It is a structured engineering runtime with Brain memory, file intelligence, patch previews, capability readiness, and creative production planning.

## Current Capability Areas

### 1. Cognitive Engineering

- Brain runtime.
- Cognitive memory.
- Visual Brain graph.
- Real deterministic Brain memory ingestion.
- Runtime health, topology, lineage, replay, recommendations, and focus views.

### 2. Software Workflows

- Main `/ai` workspace.
- Files Command Center at `/files`.
- File to Brain to Chat workflow.
- Safe Patch Preview.
- Operator surfaces for approval-oriented plan, diff, apply, checkpoint, snapshot, and test flow.

### 3. Capability Readiness

- Capability Cockpit at `/capabilities`.
- Tool adapter registry.
- Adapter readiness and blocked execution posture.
- Artifact ledger preview.
- Approval boundary visibility.

### 4. Creative Planning

- Creative Production Studio at `/creative`.
- Preview-only Blender scene planning.
- Preview-only ComfyUI workflow planning.
- Preview-only Unreal level planning.
- Storyboard and render queue planning.
- Artifact handoff preview.

## Safety Commitments

- File mutation is approval-gated and not automatic.
- Patch Preview is preview-only.
- Creative Studio is preview-only.
- Capability Cockpit does not execute Blender, Unreal, ComfyUI, render jobs, broker jobs, or PC/camera control.
- PC/camera features require explicit future session consent and are not active automation.
- Local deterministic logic is preferred for core planning.
